# A 股成交量

主页入口为 `/market-volume/`。填写 GitHub Token 后点击“更新行情”，页面触发 `.github/workflows/market-volume.yml`，由 GitHub Actions 获取行情并将本次请求的 JSON 提交到 `market-volume/results/`；页面按请求 ID 读取结果。每次更新都会创建一个结果文件和一次提交。

## 配置

1. 在 GitHub 仓库设置中允许 Actions 使用读写权限，并确保默认分支为 `master`。
2. 创建仅限此仓库、具有 **Actions: Read and write**、**Contents: Read** 权限的短期 fine-grained token。
3. 在页面中输入 Token；它仅在当前页面内存中使用，不写入浏览器存储、日志或结果文件。

## 数据口径

- 东方财富指数行情：上证 A 股指数 `1.000002`、深证 A 指 `0.399107`、科创综指 `1.000680`。指数成交量采用数据源口径；科创综指不保证覆盖全部科创板股票。科创板属于沪市，沪深合计只计算沪市与深市，不再加科创板。北交所不在本工具范围内。
- 源数据单位是手，页面显示亿股（1 手 = 100 股）。历史使用最近 30 个共同交易日的日 K 线；交易日当天使用对齐至三个市场共同最新分钟的分时量汇总，可能和源站日线有少量差异。
- 分时按北京时间 `09:30–10:30`、`10:30–11:30`、`13:00–14:00`、`14:00–15:00` 展示，开盘集合竞价的 `09:30` 记录归入第一段，其他分钟按右端点归属，收盘集合竞价包含在最后一段。未开始的时段显示“—”，尚未结束的时段显示已有成交量。午休不计入一小时交易时段。
- 非交易日或当天尚未开盘时，不把上一交易日分时标为今日。数据源不可用、日期或分钟数据不一致时任务失败，不将缺失的数据当成零。
- 行情是每次手动点击后经 Actions 抓取的一次快照，Actions 排队及数据源本身可能产生延迟，不是逐笔实时行情。页面标注抓取时间及行情截止时间，仅供参考。
