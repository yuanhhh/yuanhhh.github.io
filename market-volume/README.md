# A 股成交额

主页入口为 `/market-volume/`。填写 GitHub Token 后点击“更新行情”，页面触发 `.github/workflows/market-volume.yml`，由 GitHub Actions 获取行情并将本次请求的 JSON 提交到 `market-volume/results/`；页面按请求 ID 读取结果。每次更新都会创建一个结果文件和一次提交。

## 配置

1. 在 GitHub 仓库设置中允许 Actions 使用读写权限，并确保默认分支为 `master`。
2. 创建仅限此仓库、具有 **Actions: Read and write**、**Contents: Read** 权限的短期 fine-grained token。
3. 在页面中输入 Token；它仅在当前页面内存中使用，不写入浏览器存储、日志或结果文件。

## 数据口径

- 优先使用搜狐指数历史成交额和腾讯财经分时成交额；失败时切换到东方财富历史与分时成交额。指数分别为上证 A 股指数 `sh000002` / `1.000002`、深证 A 指 `sz399107` / `0.399107`、科创综指 `sh000680` / `1.000680`。页面显示本次实际来源。指数成交额采用数据源口径；科创综指不保证覆盖全部科创板股票。科创板属于沪市，沪深合计只计算沪市与深市，不再加科创板。北交所不在本工具范围内。
- 图表和表格展示“沪深合计”（沪市 + 深市），科创板已包含在沪市中，不重复相加。两张图均可切换柱状图或曲线图，并可选择单个系列；分时柱状图叠加趋势线。空心点表示尚未结束的时段，未开始的时段不绘制数据点。
- 页面显示亿元。搜狐历史成交额单位为万元，腾讯分时和东方财富数据单位为元；程序转换为整数分再计算，页面按 1 亿元 = 100 亿分展示。历史使用最近 30 个共同交易日的日线，腾讯日线仅用于核对交易日，**不将成交量当作成交额**。交易日当天使用对齐至三个市场共同最新分钟的分时成交额汇总，可能和源站日线有少量差异。
- 分时可选 1 小时（4 段）或半小时（8 段），分别覆盖北京时间 `09:30–11:30` 和 `13:00–15:00`。开盘集合竞价的 `09:30` 记录归入第一段，其他分钟按右端点归属，收盘集合竞价包含在最后一段。未开始的时段显示“—”，尚未结束的时段显示已有成交额，午休不计入交易时段。
- 非交易日或当天尚未开盘时，不把上一交易日分时标为今日。数据源不可用、日期或分钟数据不一致时任务失败，不将缺失的数据当成零。
- 腾讯分时接口返回当日累计成交额，程序先计算每分钟增量；腾讯的 `13:00` 午休重复记录只在与 `11:30` 累计值一致时忽略，不会重复计入。
- 行情是每次手动点击后经 Actions 抓取的一次快照，Actions 排队及数据源本身可能产生延迟，不是逐笔实时行情。页面标注抓取时间及行情截止时间，仅供参考。
